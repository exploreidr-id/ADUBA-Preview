Technology Direction

Exploring interoperability

These technologies represent ADUBA's proposed direction. Their integration and production readiness must be verified through development and testing.

Cosmos SDK

A potential foundation for a customizable, application-specific blockchain.

Cosmos EVM

Being evaluated as a route toward Ethereum-compatible application support.

CometBFT

A proposed consensus component requiring integration and reliability testing.

IBC

A priority area for researching secure interoperability with compatible networks.

The Road Ahead

Proposed Development Roadmap

This roadmap is preliminary. Priorities and timelines may change following technical assessment, team formation and funding discussions.

Phase 1 — Foundation & Code Review

Audit existing code, document requirements and assess architecture and security.

Phase 2 — Core Blockchain Development

Develop and test network components, consensus, recovery and reliability.

Phase 3 — Interoperability

Evaluate IBC integration and bridge security before any public deployment.

Phase 4 — Ecosystem Development

Explore developer programs, strategic partnerships and funding opportunities.
